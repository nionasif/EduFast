Proprietary Innovation

Direct Government Education Board Verification

Reverse-engineered live integration with educationboardresults.gov.bd
🌐 Live Verification Capabilities
Real-Time Data Fetching
  • Official Endpoint: Connects to educationboardresults.gov.bd/v2/getres.
  • Two-Step Handshake: Initializes server session cookies and fetches real-time government CAPTCHA images via /api/board/start-session.
  • Interactive CAPTCHA Modal: Student solves math CAPTCHA directly on signup.
  • Verified Data Extraction: Extracts authentic Student Name, Father's Name, Mother's Name, Institute, and GPA.
  • 37-Year Passing History: Supports passing years from 1990 to 2026, plus manual entry fallback.
  • Zero Fraud: Eliminates fake GPAs on user registration.
🔐 Concrete Technical Execution
Backend Scraper Engine
  • Executed via backend/services/scraperService.js.
  • Parses complex government JSON payload properties (r.fname, r.mname, r.inst_name, r.res_detail).
  • Employs Regex GPA extractor to capture genuine grades without fallbacks.
  • Caches verified results in local SQLite database for instant subsequent authentications.
  • Ensures anti-tampering: verified grades are locked from client-side modification.

AI & Data Science

Production Machine Learning Chance Predictor

Empirical Random Forest classifier providing data-driven admission probabilities
🤖 Scikit-Learn Model Architecture
RandomForestClassifier
  • Model: RandomForestClassifier (100 Decision Trees).
  • Training Corpus: 4,000 verified admission records (ml_engine/dataset).
  • Serialized Binary: ml_engine/models/admission_model.joblib.
  • Accuracy: 89.75% | CV Mean: 91.55%.
  • Precision / Recall: 88.22% / 99.32% | F1-Score: 0.9344.
  • Interactive modal in MLChancePredictorModal.jsx.
