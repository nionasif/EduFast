# Project Brief — EduFast

EduFast is a modern web application designed for fast, responsive, and interactive educational experiences.

## Core Vision
To provide users with a clean, fast-loading, and interactive educational platform using React and modern build tools.

## Key Objectives
- **Speed**: Optimized loading times and rendering performance.
- **Interactivity**: Smooth UI transitions and rich interactive React components.
- **Maintainability**: Clean project structure and strict linting with `oxlint`.

## Core Constraints
- Must run cleanly on Vite 8 and React 19.
- No heavy libraries; prefer lightweight or custom components.
- Maintain 100% clean linting using `oxlint`.
