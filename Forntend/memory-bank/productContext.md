# Product Context — EduFast

## User Demographics & Goals
- **Students / Learners**: Seek quick access to lessons, tests, or courses without loading lag or complex interfaces.
- **Instructors**: Want a simple way to present educational materials clearly.

## User Experience (UX) Principles
- **Fast First**: Animations should be micro-animations; no long loading screens.
- **Clarity**: Avoid busy layouts. Focus on reading and learning content.
- **Mobile Friendly**: The layout must adjust smoothly to fit any screen size.
