# 🎬 EduFast Course Videos Directory

এখানে কোর্সের সকল টপিক ও লেকচারের ভিডিও ফাইল রাখা যাবে।

### অনুমোদিত ফরম্যাট:
- `.mp4` (সবচেয়ে বেশি রেকমেন্ডেড)
- `.webm`
- `.mkv`

### ব্যবহার নির্দেশিকা:
১. আপনি আপনার ভিডিও ফাইলটি সরাসরি এই ফোল্ডারে কপি করে রাখতে পারেন:
   `EduFast\backend\uploads\videos\`
২. অথবা এডমিন প্যানেল থেকে "Upload Video File" বাটনে ক্লিক করে ফাইলটি সিলেক্ট করলেও স্বয়ংক্রিয়ভাবে এখানে সেভ হয়ে যাবে।
৩. সার্ভারে এই ভিডিওটি `http://localhost:5001/uploads/videos/আপনার_ফাইলের_নাম.mp4` লিঙ্কে সরাসরি প্লে হবে।
